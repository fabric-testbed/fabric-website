## Disclaimer

This Q&A tool is currently in a developmental phase and answers generated by the tool may not yet provide fully accurate or comprehensive responses to all queries. As we continue to improve the tool, we will incorporate user feedback and optimize it based on the types of questions being asked. Please use this tool with the understanding that it is still evolving, and we appreciate your patience as we refine its capabilities. We invite you to provide feedback about this tool.

## Technology Used

This tool uses OpenAI GPT-4o-mini for LLM inferencing. We are using the open-source [all-MiniLM-L6-V2 model](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) for embeddings and [BAAI/bge-reranker-v2-m3](https://huggingface.co/BAAI/bge-reranker-v2-m3) for reranking. For the vector stores database, we are currently using ChromaDB in production. We use the langchain framework to integrate all the software components.

## Data Sources

Our RAG system is built upon FABRIC documentation pages as well as historical forum threads, providing comprehensive coverage of both official documentation and community knowledge.   

## Data Collection and Privacy

While we do not collect any information regarding the user’s identity, we do review the questions submitted and the tool’s response for quality assurance and tool improvement purposes.
