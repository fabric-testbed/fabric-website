-   NEU workflow uses the OpenCloud Testbed (OCT) toolchain. OCT toolchain builds on Xilinx's OpenNIC implementation. For more information please refer to [OCT documentation](https://github.com/OCT-FPGA/P4OpenNIC_Public/tree/main/OpenNIC-Getting-Started).
-   _[FPGA Initialization Notebooks for ESnet and NEU Workflows](https://artifacts.fabric-testbed.net/artifacts/3339af84-fa5b-4f54-a915-fbbbfb44226d)_ Artifact consists of a working example on how to deploy a pre-compiled P4 program on FABRIC.
