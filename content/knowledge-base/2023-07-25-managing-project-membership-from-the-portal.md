Please check the article [FABRIC User Roles and Project Permissions](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/) for more information.

If you are **Project Lead**, you will be able to create new projects and manage project membership including project owners/ members.

Once you create a project you automatically become the first [Project Owner](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/).

An example of a Project Owner is your Co-PI or perhaps a TA for your class. An example of a Project Member is a graduate student working on your project or a student in your class.

For managing project owners, please go to the Project Detail page and click Project Owners tab.

#### **Add Project Owners/Members**

1.  search people by name or email;
2.  select the user by clicking "+" button;
3.  review the user(s) to add then click "Add to Project Owners/ Members".

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/07/add-project-members-1024x507.png) ![](https://learn.fabric-testbed.net/wp-content/uploads/2023/07/add-project-members-2-1024x348.png)

#### **Manage Project Owners/ Members**

1.  view, filter and sort existing project owners;
2.  use check-boxes to select users to delete.

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/09/s3-1024x395.png)

[**Project Owners**](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/) can add and remove their [Project Members](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/). For managing project members, please go to the Project Detail page and click Project Members tab and the process of adding/ managing project members are similar to the guide above.

The second option to add project members is **Batch Upload.** You can use a CSV file with user emails as the first column and the limit is 300 rows per CSV file. After uploading the CSV file, portal will search every user in the file automatically and shows any user that cannot be found in the database.

Regardless of the mode by which you are adding new members into the project, those members must have completed the enrollment to the FABRIC portal and logged in for the first time themselves. Until then they cannot be added to the project.

The project member batch update could take a while and the project will be locked temporarily from making more changes to the membership until the project membership change is fully completed. A toast message will show up once all project members are successfully added.

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/09/s5-1024x346.png) ![](https://learn.fabric-testbed.net/wp-content/uploads/2023/09/s4-1024x689.png)

It is safe to navigate to other parts of the Portal during project membership update process. A toast message with link to the updated project will pop-up if you navigate to other pages.
