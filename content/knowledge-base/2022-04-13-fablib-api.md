The FABLib API is the recommended way to use FABRIC. FABLib is a Python library that simplifies the native FABRIC interfaces and adds many additional capabilities that are commonly used to create experiments.

The easiest way to get started using FABLib is to use the example Jupyter notebooks that are preinstalled in the FABRIC JupyterHub.

-   FABLib API documentation is hosted at [https://fabric-fablib.readthedocs.io/](https://fabric-fablib.readthedocs.io/).
-   FABLib source code is at [https://github.com/fabric-testbed/fabrictestbed-extensions/tree/main/fabrictestbed\_extensions/fablib](https://github.com/fabric-testbed/fabrictestbed-extensions/tree/main/fabrictestbed_extensions/fablib).
