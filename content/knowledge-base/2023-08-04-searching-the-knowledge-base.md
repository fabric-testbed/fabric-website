This site (aka 'The Knowledge Base') has multiple types of documentation which are all searchable. However the search is not unified to produce more relevant results quicker. There are three main content types within the Knowledge Base:

-   Knowledge Base articles. These can be searched for using the main search bar near the top:

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/08/Screen-Shot-2023-08-04-at-3.07.05-PM.png)

-   The messages in the forums can be searched for separately using the search form at the top of the forums:

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/08/Screen-Shot-2023-08-04-at-3.07.13-PM.png)

-   The FABlib API is presented using _readthedocs_ site accessible [from this page](https://learn.fabric-testbed.net/knowledge-base/fablib-api/), and can be searched using a search form near the top of [readthedocs](https://fabric-fablib.readthedocs.io/en/latest/) interface:

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/08/Screen-Shot-2023-08-04-at-3.07.40-PM.png)
