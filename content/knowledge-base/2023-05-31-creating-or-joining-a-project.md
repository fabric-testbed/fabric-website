## Creating a Project

Only users that have been vetted for the position of a [Project Lead](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/) can request to have new projects created for them. Once a new project is created, the Project Lead can assign additional project members, request resources, and deploy slices within FABRIC. You can request to be vetted for a Project Lead position from the Portal Experiments page.

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/05/Screenshot-2026-02-02-at-4.53.30-PM.png)

When managing a new project it is important to think through its purpose and its membership as FABRIC [permissions](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/) are granted on a per-project basis. Also it is important to fill out a description for the project as those are public by default (searchable by other FABRIC users). You can select your project not to be public using checkmarks in the project 'Basic Information' tab.

## Joining a Project

Now that your account is enrolled you can access the FABRIC portal but you cannot yet use the testbed. Before you can use the testbed you must join [an active project](https://learn.fabric-testbed.net/knowledge-base/fabric-user-roles-and-project-permissions/). A project owner must add you to a project.

A Project Lead or a Project Owner can add new Owners and Members by first navigating to the project via Experiments/Projects & Slices. Using the search box you can find the user you want to add (minimum 4 consecutive letters of email or name are required for search) and click 'Add' next to their name.

![](https://learn.fabric-testbed.net/wp-content/uploads/2023/05/project-membership-ui-1024x336.png)

The only way to join a project is for the project owner to add you one of their existing projects. Please contact your professor or research lead to be added to your team's project.

Note also that the portal provides the ability to add multiple project members from a CSV file where the first column is their email (as used to sign up for a FABRIC account). Use the 'Batch Upload' tab shown above and follow the prompts.

Adding multiple members especially via Batch option can take a significant amount of time (minutes). You can navigate away from the page once you click 'Save' however project membership manipulation will be locked until all the updates have completed. A banner will announce when the process is completed and you will be able to see if any errors occurred when adding project members.
