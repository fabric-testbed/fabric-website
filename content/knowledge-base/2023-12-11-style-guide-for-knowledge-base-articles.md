There are plenty of template Blocks available in this [WordPress theme](https://herothemes.com/wordpress-knowledge-base/). This article introduces recommended frequently-used block types for style consistency across the knowledge base articles.

\[ivory-search id="2367" title="Default Search Form"\]

## Getting Started

The Blocks allow you to add interactive styled content to your articles from the WordPress article editor. You can see in real time how the content will look to the readers as it is being edited.

Add the block you want to use with the **\+** button. Then input block name in the **search box** or click **Browse all** button to find the block you need.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-2-1024x522.png) \*Add block -> Search/ Browse all\*

## Heroic Blocks - Messages

Add a message callout. Click on the **!** icon to choose styles from **Success**, **Alert**, **Danger** and **Information**.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-5-1024x999.png)

## Accordion

Each pane of the accordion can contain any other type of blocks. There are four initial styles to choose from and please use the third one for style consistency.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-7-815x1024.png)

## Tabs

Each pane of the tabs can contain any other type of blocks. There are four initial styles to choose from and please use the first one for style consistency.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-8-652x1024.png)

## Heading

**Heading** introduces new sections and organize content to help visitors (and search engines) understand the structure of your content. The default size for **Heading** is H2.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-3.png)

## Paragraph

**Paragraph** is the basic building of all narrative. After inserting the paragraph block and content, by clicking the content, there will be a toolbar popup on top.

1.  Change text alignment: align text left/ center/ right;
2.  Bold;
3.  Italic;
4.  Insert Link;
5.  Displays more block tools as shown in the dropdown list below.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-4-1024x567.png)

## List

Create a bulleted or numbered list.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-10-1024x267.png)

## Quote

Give quoted text visual emphasis.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-9-1024x234.png)

## Table

Create structured content in rows and columns to display information. The column count and row count can be preset before creating table or can be modified by inserting and deleting row/ column.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-11-1024x413.png) ![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-12-1024x476.png)

## Preformatted

Add text that follows your original spacing, tabs and styling. you want to use **Preformatted** block when you need to display text _exactly_ as you typed it. Keep in mind that all spaces, tabs, and carriage returns will be preserved.

## Code

Display code snippets that respect your spacing and tabs. You can also specify the code language or add title for the code block from panel on the right.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-22-1024x569.png)

## Image

Add image by uploading an image file, picking one from your media library or add one with a URL (tip: pasting a screenshot directly will also work).

Then you can edit the image style and properties in toolbar above or from panel on the right.

![](https://learn.fabric-testbed.net/wp-content/uploads/2022/06/image-24-1024x578.png)
