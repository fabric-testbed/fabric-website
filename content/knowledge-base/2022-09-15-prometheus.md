See the Prometheus web site at [prometheus.io](https://prometheus.io) for more information about Prometheus in general.  
Fabric uses Prometheus as the main metric gathering system for both the Fabric infrastructure and for an instrumentized Fabric Experiment. It is designed to collect and query numerical data very efficiently. There are lots of "exporters" available that make metrics readily available from many existing software bases.
