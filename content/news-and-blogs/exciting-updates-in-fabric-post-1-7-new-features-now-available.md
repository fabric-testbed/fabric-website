Dear FABRIC Community,

We are thrilled to announce the release of FABRIC 1.7, packed with a host of new features.

## Portal Enhancements

- Funding, Community, and Matrix Link Support for projects
- Public Project List for unauthenticated users
- Level-2 Data on Site Detail Page
- Time Filter for resource availability
- Future Lease Start Time for slices
- FPGA Support in Slice Builder

## New Tools and Features

- **Artifact Manager** — Upload and share notebooks or papers with other experimenters
- **Measurement Metrics** — Public Metrics, Infrastructure Metrics, Optical Data, Latency Monitor
- **Control Framework/FabLib** — Advanced Scheduling, Explicit Route Options, Sub Interfaces, Port Mirroring

## Enhanced Resource Availability

- Granular Resource Information per host
- Validate Slice before submission
- AL2S Interconnect for public cloud connections (Google Cloud, AWS, Azure)
- OVS Switches with Basic NICs

## New OS Images

New images include: default_rocky_9, default_debian_12, default_fedora_39, default_fedora_40, default_freebsd_14_zfs, default_ubuntu_24, default_kali, attestable_bmv2_v2_ubuntu_20.

Best regards,
The FABRIC Team
