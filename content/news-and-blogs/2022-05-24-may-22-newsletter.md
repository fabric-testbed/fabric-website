#### **What’s New With FABRIC?**

_An update from Ilya Baldin, FABRIC Principal Investigator_

The FABRIC team is continuing to build out the testbed footprint. After many vendor logistics-related delays we now have firm dates for the delivery of the remaining Phase 1 sites at Clemson, UCSD, FIU, GPN/UMKC, while completing the orders for Phase 2 site hardware. Release 1.2 of the FABRIC software stack is being readied for production deployment in the upcoming days. This release will include new experimenter features like ‘Facility Ports’ to create experiment slices that include resources external to FABRIC, ‘Mirror Ports’ that allow mirroring traffic from the dataplane into a slice and a number of others. Be sure to check the [Release Notes](https://cMhdn04.na1.hubspotlinks.com/Ctc/T9+113/cMhdn04/VWDW7X3lHw-LW46bvyn8VFdZ2W5l3Nw34KsvJBN6rgBqy3q90pV1-WJV7CgPTrW7P-xtk6QsMWZW6hMKZ08BNHY_W7P1CG38xB6FHW4X555W7kBbcHW3v7G_67R_W6yVRvVm22nGm21W4GbYdZ8q_h-XW7bqJbF2JHMVQW5WPQ9C1s2zXjN5RwvRsSfYw8N16qGXz69qpHW4KJWdS4cq8DKW7pd60G4pNY11W5fbZyd31VGB4W3sLkl78QsWWRN3vL4lr8vpGLW1w_57G3qRcNJW78SNZZ92n8TRW13Jxp-3HJyfHW1_PKJy6_Sjd0W1qYBcj3qFttHW3RFpbZ8H_zhHW6Qyrz88M9wYHW65wsR16qGFBBW9dHj4k5WQL-bW6HGgD094N3-_3mPS1)section for detailed updates when they become available. 

We are working with our partners at [Open Cloud Testbed](https://cMhdn04.na1.hubspotlinks.com/Ctc/T9+113/cMhdn04/VWDW7X3lHw-LW46bvyn8VFdZ2W5l3Nw34KsvJBN6rgBpG3q8_wV1-WJV7CgKh3W4t_Pp11d7Z59W7-2YBz38c_JGW5nVGwW7vS4TfM4c66wZzjT0W82N16R2WxZ_0W4FxPZL6rYrSXW6qxn9J6hnjnqW6l6QGy7N8CGXW6wd8n85557SfW8g2b5F6YKN-LW7TT75N7S812sW1xs4sh1mqXF_W4vr8b-7KQggkN3w3s4rfJyb0W8jlSzz6TqFhjW2QKXYD58YlBMW3bvdXN3MTm5_W8cbDtW3Nx2NKW18wzmr644hqNW5X48HR3K57y136hv1) (University of Massachusetts and Northeastern University) to create FPGA-based P4 experiment workflows usable on FABRIC, stay tuned for more updates on it this summer. #### FABRIC: A Testbed of Testbeds

_Participating Testbeds and Facilities_

FABRIC is a testbed of testbeds, helping users experiment using multiple testbeds. Like Lego blocks, users can get accounts on several testbeds and build an experiment using all of them. Additionally, testbeds can be powered by FABRIC. FABRIC can support testbeds as an underlying infrastructure, while not necessarily exposing the FABRIC interfaces to their users.

#### Defining FABRIC

_A glossary for common terms used by our researchers_

**Identity Token:** A signed statement from a trusted entity carrying identity attributes, which are used by individual Control Framework and Measurement Framework agents to make resource allocation authorization decisions.

**Identity Provider (IdP):** An agent run on behalf of an institution capable of asserting a number of institution-specific identity attributes about a principal
