*Featuring the best resources for experiment management, federation with testbeds, large scale data movement, and more!*

We're excited to announce the [Tools Page](https://learn.fabric-testbed.net/article-categories/tools/) — a Knowledge Base section featuring articles on command-line tools for managing FABRIC experiments, federating with other testbeds and public clouds, supporting large-scale data movement and more.

**FABRIC Federation Extension (FabFed)** — A software stack for running large experiments across multiple testbed and cloud providers. [Learn more](https://learn.fabric-testbed.net/knowledge-base/fabric-federation-extension-fabfed-users-manual/).

**SliceCommander** — A tool for working with FABRIC slices interactively using a shell-like command interpreter. [Learn more](https://learn.fabric-testbed.net/knowledge-base/using-slicecommander-with-fabric/).

**FABRIC Experiment Framework (FABExp)** — A Jupyter-based GUI that allows users to manage their experiments. [Learn more](https://learn.fabric-testbed.net/knowledge-base/fabric-experiment-frameworkfabexp/).

Have you built a tool on FABRIC that should be featured? Please reach out to [KC Wang](mailto:kwang@clemson.edu).
